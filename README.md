# ⚔️ 1 ใน 10,000 — Aincrad Life Simulator (Sword Art Online)

เกมจำลองชีวิตและเอาตัวรอด (Life & Survival Simulator) บนเว็บเบราว์เซอร์ ที่ได้แรงบันดาลใจจากเกมไวรัล **"1 ใน 65 ล้าน"** ผสมผสานกับโลกและเนื้อเรื่องจริงของ **Sword Art Online (Aincrad Arc)** ตามนิยาย ไลท์โนเวล อนิเมะ และมังงะ

---

## 📖 เรื่องย่อ (Story Lore)
> **6 พฤศจิกายน 2022** — คุณคือ 1 ใน 10,000 คนแรกที่ได้เป็นเจ้าของเครื่อง NerveGear และเชื่อมต่อเข้าสู่โลกเสมือนจริงของเกม **Sword Art Online**...  
> ทว่าเมื่อถึงเวลาพลบค่ำ ปุ่ม **Log Out** ได้อันตรธานหายไป และร่างยักษ์สีเลือดของ **คายาบะ อากิฮิโกะ** ได้ปรากฏตัวขึ้นพร้อมกฎเหล็กมรณะ:  
> **"หาก HP ของคุณกลายเป็น 0 หรือมีใครพยายามถอดหมวกเนิร์ฟเกียร์ในโลกจริง คลื่นไมโครเวฟจะทำลายสมองของคุณทันที... ทางรอดเพียงหนึ่งเดียวคือพิชิตชั้นที่ 100!"**

คุณจะเอาตัวรอดจากความกลัว คมดาบของมอนสเตอร์ และความมืดมิดในใจมนุษย์ได้อย่างไร?

---

## 🌟 จุดเด่นของระบบเกม (Key Features)

1. **ระบบสุ่มตัวละครใน 10,000 คน (Character Roll):**
   - **สุ่มพื้นเพ (Backgrounds):** Beta Tester (10%), Hardcore MMO Gamer (25%), Casual Gamer (40%), Newbie VR (20%), และคนยืมเนิร์ฟเกียร์คนอื่นมาลองเล่น (5%)
   - **สุ่มอาวุธเริ่มต้น:** ดาบมือเดียว (One-Handed Sword), เรเปียร์ (Rapier), ค้อนและโล่ (Mace & Shield), ดาบสองมือ (Two-Handed Sword), มีดสั้น (Dagger), หอก (Spear)
   - **สเตตัสเริ่มต้น:** HP, Col (เงินในเกม), Sanity (สติ/สภาพจิตใจ), Courage (ความกล้าหาญ)

2. **ไทม์ไลน์และเหตุการณ์จริงตาม SAO Lore (40+ Events):**
   - **วันที่ 1 (6 พ.ย. 2022):** การประกาศของคายาบะ, การล่าหมูป่า Frenzy Boar, กับดักของ Coper, อนุสาวรีย์แห่งชีวิต (Monument of Life) ในปราสาทเหล็กสีดำ
   - **เดือนที่ 1:** การประชุมของเดียร์เบล (Diavel), การบุกบอสชั้น 1 (Illfang the Kobold Lord), การถือกำเนิดของฉายา "Beater"
   - **การเลือก Life Path:**
     - ⚔️ **Frontliner:** กองหน้าล่าบอส
     - 🐺 **Solo Player:** นักดาบพเนจร
     - 🔨 **Merchant & Craftsman:** ช่างตีเหล็ก/พ่อค้าใน Safe Zone
     - 🛌 **Refugee:** ผู้ลี้ภัยซ่อนตัวในเมืองเริ่มต้น
     - 🩸 **Orange Player:** สายมืด/กิลด์ฆาตกร PK
   - **เหตุการณ์สะเทือนใจและบุคคลในตำนาน:** โศกนาฏกรรมกิลด์แมวดำใต้แสงจันทร์ (Moonlit Black Cats) ชั้น 27, ซิลิก้าและพีน่า ชั้น 35, ร้านตีดาบลิซเบ็ธ ชั้น 48, สงครามกวาดล้าง Laughing Coffin, การพบกับ "ยุย (Yui)" ชั้น 22, บอสชั้น 74 (The Gleam Eyes) และการเปิดเผยดาบคู่ Starburst Stream, บอสชั้น 75 (The Skull Reaper) และการดวลตัดสินกับคายาบะ!

3. **ฉากจบหลากหลายกว่า 25+ แบบ (Ending Gallery):**
   - 💀 **Bad Ends:** ตายจากหมูป่าวันที่ 2, โดนถอดเนิร์ฟเกียร์ในโลกจริง, ติดกับดักกล่องสมบัติชั้น 27, ลืมซื้อคริสตัลวาร์ป, ตายในศึก The Gleam Eyes, ฯลฯ
   - 🕊️ **Peaceful / Bittersweet Ends:** ซื้อบ้านไม้สงบสุขริมทะเลสาบชั้น 22, สหายแท้แห่งกิลด์ฟูรินคาซันของไคลน์, ผู้รอดชีวิตไร้ชื่อเสียง
   - 💰 **Merchant Ends:** ราชาแห่งการค้าแห่ง Aincrad, ช่างตีดาบระดับตำนานลูกศิษย์ลิซเบ็ธ, ยอดเชฟเนื้อกระต่ายหายาก
   - 🏆 **Legend Ends:** วีรบุรุษผู้พิชิต Aincrad, จอมชิง Last Attack Bonus, ผู้อารักขาดวงใจของยุย (Yui's Heart), Beater ผู้กอบกู้

4. **UI/UX สไตล์ Sword Art Online & ระบบเสียง:**
   - ธีมมืดนีออนส้ม/ฟ้า Hexagonal
   - หลอดเลือด HP เฉียงมุมสไตล์ SAO ดั้งเดิม (สีเขียว -> เหลือง -> แดงกระพริบเมื่อเลือดวิกฤต)
   - ระบบเสียงประกอบสังเคราะห์ด้วย Web Audio API (มีปุ่มเปิด/ปิดเสียง) เล่นได้ 100% โดยไม่ต้องโหลดไฟล์เสียงภายนอก

## 🚀 วิธีนำขึ้น GitHub และเปิด GitHub Pages ให้เพื่อนเล่น

### ขั้นตอนที่ 1: สร้าง Repository ใหม่บน GitHub
1. ล็อกอินเข้า [GitHub](https://github.com)
2. กดปุ่ม **"New repository"**
3. ตั้งชื่อ Repository เช่น `sao-life-sim` หรือ `aincrad-life-simulator`
4. เลือกเป็น **Public**
5. **ไม่ต้อง** ติ๊ก "Add a README file" (เพราะเรามีไฟล์พร้อมอยู่แล้ว)
6. กดปุ่ม **"Create repository"**

### ขั้นตอนที่ 2: อัปโหลดโค้ดขึ้น GitHub ผ่าน Git
เปิด Terminal หรือ PowerShell ในโฟลเดอร์นี้ แล้วรันคำสั่ง:

```bash
git remote add origin https://github.com/USERNAME/sao-life-sim.git
git branch -M main
git push -u origin main
```
*(เปลี่ยน `USERNAME` เป็นชื่อผู้ใช้ GitHub ของคุณ)*

### ขั้นตอนที่ 3: เปิดใช้งาน GitHub Pages
1. ไปที่หน้า Repository ของคุณบน GitHub
2. กดแท็บ **Settings** -> เมนูด้านซ้ายเลือก **Pages**
3. ในส่วน **Build and deployment**:
   - ตรงช่อง **Source** ให้เลือกเป็น **GitHub Actions**
4. ตัว Action ใน `.github/workflows/deploy.yml` จะทำการ Deploy หน้าเว็บให้อัตโนมัติภายใน 1-2 นาที!
5. คุณจะได้ลิงก์ เช่น `https://USERNAME.github.io/sao-life-sim/` สามารถส่งให้เพื่อนๆ เล่นได้ทันทีทุกที่ทุกเวลา!
